# Resources / Kaynaklar

## English

- [Official YARA documentation](https://yara.readthedocs.io/en/latest/) — the main reference for installation, syntax, modules, and command-line usage.
- [ZAYOTEM Malware Analysis Feed](https://github.com/ZAYOTEM/malware-analysis-feed) — a learning reference showing practical, case-based uses of analysis scripts and YARA rules. The project is available under the MIT License, with `Copyright (c) 2022 ZAYOTEM`.

This list is intentionally short for the first version and can grow as later labs introduce new topics. ZAYOTEM's repository was used only as a reference; its malware samples, scripts, and rules are not included in this repository.

## Türkçe

- [YARA resmî dokümantasyonu](https://yara.readthedocs.io/en/latest/) — kurulum, söz dizimi, modüller ve komut satırı kullanımı için ana kaynak.
- [ZAYOTEM Malware Analysis Feed](https://github.com/ZAYOTEM/malware-analysis-feed) — analiz script'lerinin ve YARA rule'larının vaka temelli pratik kullanımını gösteren bir öğrenme kaynağı. Proje, `Copyright (c) 2022 ZAYOTEM` bildirimiyle MIT Lisansı altında sunulmaktadır.

Bu liste ilk sürüm için bilinçli olarak kısa tutulmuştur ve ilerideki lab'ler yeni konular sundukça genişletilebilir. ZAYOTEM reposu yalnızca kaynak olarak incelenmiş; bu repoya onun malware örnekleri, script'leri veya rule'ları eklenmemiştir.
